# color-picker
Tap a color, and see what goes with it.

A small vanilla HTML/CSS/JS page for painters:

- Take a photo (or choose one from your library) and tap anywhere to sample a color, with a magnifier and optional 5×5 / 11×11 averaging.
- The page background becomes the picked color; recent picks are kept in "Picked so far".
- See complementary, split complementary, analogous, triadic and tetradic harmonies, plus tints, shades, tones and a muted-complement ramp.
- Switch between the painter's RYB wheel and the light RGB wheel.

No build step: open `index.html`, or serve the folder with any static host (e.g. GitHub Pages).
